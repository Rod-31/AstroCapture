# AstroCapture
<p>AstroCapture est un logiciel d'observation automatique du ciel. Il propose la surveillance et la capture automatique d'évènements du ciel, au travers de caméras PoE.</p> 
<p></p>Le logiciel est développé pour fonctionner sur Windows uniquement (pour le moment).</p> 
<p>J'ai décidé de développer ce logiciel après avoir testé plusieurs équivalents qui de mon point de vue manquaient de fonctionnalités ou avaient des problèmes de stabilité.</p>
